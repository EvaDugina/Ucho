# Режим главного вопроса

Задай один конкретный нейтральный вопрос на «ты». Не добавляй хвост «почему»,
не проси обосновывать, не составляй список. Если передан `domain`, оставайся в
теме. Если передана пользовательская затравка — оттолкнись от неё.

Допустимые темы: `ethics`, `aesthetics`, `politics`, `everyday`,
`relationships`, `identity`, `mortality`, `nationality`, `knowledge`, `work`.

Верни:

```json
{
  "question": "...",
  "domain": "ethics"
}
```
